ОСНОВНЫЕ СЦЕНАРИИ USE CASE
Приложение «Планировщик событий»

UC-01. Регистрация пользователя
Актор: Пользователь.
Предусловие: Пользователь ещё не зарегистрирован.
Основной сценарий:
1. Пользователь вводит email, пароль и имя.
2. Отправляет запрос POST /user/signup.
3. Система проверяет уникальность email.
4. Система регистрирует пользователя.
Результат: HTTP 201, регистрация успешна.
Альтернатива: HTTP 409, пользователь уже существует.

UC-02. Вход в систему
Актор: Пользователь.
Предусловие: Пользователь зарегистрирован.
Основной сценарий:
1. Пользователь вводит email и пароль.
2. Отправляет запрос POST /user/signin.
3. Система проверяет учётные данные.
4. Система подтверждает успешный вход.
Результат: HTTP 200.
Альтернатива: HTTP 403 при неверном пароле;
HTTP 404 при отсутствии пользователя.

UC-03. Просмотр списка событий
Актор: Пользователь.
Основной сценарий:
1. Пользователь отправляет GET /event/.
2. Система получает список событий.
3. Система возвращает список пользователю.
Результат: HTTP 200, список событий.
Если событий нет, возвращается [].

UC-04. Просмотр события по ID
Актор: Пользователь.
Основной сценарий:
1. Пользователь указывает ID события.
2. Отправляет GET /event/{id}.
3. Система находит событие.
4. Система возвращает его данные.
Результат: HTTP 200.
Альтернатива: HTTP 404, событие не найдено.

UC-05. Создание события
Актор: Пользователь.
Основной сценарий:
1. Пользователь заполняет данные события.
2. Отправляет POST /event/new.
3. Система проверяет формат данных.
4. Система добавляет событие в список.
Результат: HTTP 200, событие создано.

UC-06. Удаление события
Актор: Пользователь.
Основной сценарий:
1. Пользователь указывает ID события.
2. Отправляет DELETE /event/{id}.
3. Система находит и удаляет событие.
4. Система подтверждает удаление.
Результат: HTTP 200.
Альтернатива: HTTP 404, событие не найдено.

UC-07. Удаление всех событий
Актор: Пользователь.
Основной сценарий:
1. Пользователь отправляет DELETE /event/.
2. Система очищает список событий.
3. Система подтверждает удаление.
Результат: HTTP 200, список пуст.
